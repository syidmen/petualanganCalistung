`layers.json` mencatat setiap pemakaian gambar, node Figma, posisi dalam persen, ukuran pada bidang 1133 × 744, serta rotasinya. `dimensions.json` mencatat dimensi root dan viewBox masing-masing SVG. SVG dipakai sebagai elemen gambar tanpa mengubah file aslinya. Semua teks HTML tetap dapat diedit pada file halaman terkait.
